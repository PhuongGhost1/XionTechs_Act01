## Deviations from the design doc

- tailwind.command.config.js: the five translucent tokens (hair, hairStrong, ghost, grid, signalWash) are NOT plain rgb(var(--x) / <alpha-value>). They use a function colour rgb(var(--x) / calc(var(--x-a) * <opacity>)) so that border-hair means ink-2 at 14% by default (doc 5.1) and still accepts modifiers. The other ten keys use the exact <alpha-value> form.
- Pre-paint script in concepts/command/index.html: reduced-motion makes data-motion 'off' unless the visitor saved xt-motion='on'. This follows doc 7.2 ('a visitor can turn it on deliberately'); the task text said plainly 'off when prefers-reduced-motion'.
- Track heights are in lvh (tokens.css --track-*) per doc 10.1 ('svh stage, lvh tracks'); doc 5.3 states them as svh. Numbers are identical.
- Content group named `process` is exported from content/process.js as processContent (avoids shadowing Node's global) and re-exported as `process` and as content.process.
- Doc 8.5 puts the hotspot geometry test in hotspots.test.js, owned by WP5. I put the full geometry assertions (sizes, 0..100, unique ids and codes, overlap <= 5% of the smaller except documented todo/mstodo containment) in content.test.js as the task asked. WP5 can add hotspots.test.js on top.
- Extra files beyond the tree of 11.2: styles/fonts.css, content/{wrap,validate,select}.js, runtime/{build,flow}.js, ui/{cx,kinds}.js, TokenStory.jsx, contract/{attributes,stations,anchors}.test.js. Extra exports: scrollToProgress, remeasureTracks, progressToScrollY, stationAt, getCoreRect, useHtmlAttribute, useTrack, startGovernor.
- ESLint zero-state guard is generated per folder depth (0 to 5), because one pattern cannot express 'outside this folder'. Folders nested deeper than 5 levels under src/concepts/command are not covered; none are planned. The guard also bans the old src/App*, src/index.css and the three removed libraries.
- Fonts: only the latin @font-face rules are declared (own fonts.css, same unicode-range as fontsource), not the full fontsource wght.css, so the page ships two woff2 files (about 52 kB). Metric-matched fallbacks were measured with fontkit against Arial and Courier New (Geist: size-adjust 106.1%, ascent 94.72%, descent 27.8%; Mono: 99.98%, 100.52%, 29.5%). Geist has no glyph for U+2192 in the latin range, so arrows are drawn (Button) and never typed.
- The brief's mailto body template is not spelled out in doc 4.8; I wrote it (DRAFT, in content/contact.js mail.*) as greeting, intro, services list, 'I looked at' list, note. For an empty brief the sections are simply omitted rather than printing '( nothing selected yet )'.
- CLAUDE.md on this branch had no 'Concept pages' section to replace (already removed by the start-from-zero commit), so I appended a new 'Concept 01 v2' section (CRLF kept) instead of replacing one.
- Not done by design (out of WP0 scope): PROMPT_LOG.md untouched; no scripts/command-qa.mjs (WP6); no real three.js scene, mark.js or layouts.js (WP2); `?debug=hotspots` overlay (WP5).
